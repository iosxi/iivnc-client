# iivnc-client

Windows 10 / 11 用の VNC ビューアです。ほかの PC の画面を見たり操作したりします。
相手側は [iivnc-server](../iivnc-server) がおすすめですが、ふつうの VNC サーバー
(TigerVNC など。RFB 3.3 / 3.7 / 3.8 で VNC 認証か認証なしのもの)にもつながります。

- **インストール不要。** `iivnc-client.exe` を好きな場所に置いて起動するだけ。ランタイムも DLL も要りません。
- **レジストリを使わない。** 設定・接続先の履歴・覚えたパスワードは exe と同じ場所の `iivnc-client.ini` だけ。
- **軽い。** exe 1 個(約 290KB)。画面が止まっている間の CPU 使用はゼロ(2026-10-04 実測)。
- **速い。** 下の「速さのための工夫」を参照。

## 使い方

1. `iivnc-client.exe` を起動し、サーバー(相手の PC のアドレスや名前)とパスワードを入れて「接続」。
   - 書き方: `192.168.1.10`、`pc-name`、`pc-name:1`(ディスプレイ 1 = ポート 5901)、`host::5901`(ポートを直接)、`[fe80::1]`
   - 「覚える」にすると、次からその接続先を選ぶだけでパスワードが入ります。
2. 相手の画面が窓に出ます。窓の大きさに合わせて縮めて表示します(等倍にもできます)。
3. **F8** でメニュー(全画面、窓に合わせる / 等倍、画質、描画、Ctrl+Alt+Del を送る、見るだけ、切断 など)。
   同じものが窓のシステム メニュー(タイトル バーの右クリック)にもあります。
4. **Ctrl+Alt+Enter** で全画面の切り替え。全画面の間は、Windows キーや Alt+Tab も相手へ送ります
   (窓のときも送りたければ、メニューの「窓でも Windows キーなどを送る」)。
5. 全画面のときに**画面の上端へマウスを当てる**と、帯が出ます(「窓に戻す」「メニュー」「最小化」「切断」)。
   キーが相手へ行ってしまって抜けられないときも、これで窓に戻せます。

コマンド ラインでもつなげます: `iivnc-client.exe 192.168.1.10 -fullscreen`

### ファイルのコピー＆貼り付け

iivnc-server と iivnc-client の間で、エクスプローラーのファイルをコピー＆貼り付けで受け渡せます(両方向)。

1. 片方の PC のエクスプローラーで、ファイルやフォルダを**コピー**する(Ctrl+C)。
2. もう片方の PC のエクスプローラーで、置きたいフォルダに**貼り付け**る(Ctrl+V)。

- コピーした時点で渡すのはファイルの一覧(名前・大きさ・日時)だけです。**中身は貼り付けたときに送ります。**
  貼り付けると、Windows のふつうのコピーの画面(進み具合・キャンセル)が出ます。
- 中身は VNC の接続の中で運ぶので、ファイアウォールに新しい許可は要りません。
- 「切り取り」でも、元のファイルは消さずにコピーになります。
- **見るだけ**の接続(見るだけのパスワード、サーバーの「見るだけにする」、ビューアの「見るだけ」)では使えません。
- 相手が iivnc でないとき(ほかの VNC)は使えません(何も送りません)。
- サーバーがサービスとして動いているときも使えます(ログインしている間)。そのときサーバー側でコピーしたものは、
  通知領域のアイコン(ログインしている人の権限で動く)が見つけて渡します。ファイルはログインしている人の権限で読みます。

### 描画(GDI / GPU)

接続の画面の「描画」か、メニューの「描画」で選びます。つないだままでも切り替えられます。

- **GDI(既定)** … メモリが少ない(UltraVNC のビューアと同じくらい)。窓に合わせて縮めると、
  文字が少し粗く、描くのも遅くなります。
- **GPU** … 拡大縮小を GPU(D3D11)で行い、縮めても文字がきれい。その分メモリを 約 70〜100MB 多く使います。
  GPU から GDI へ戻しても、読み込んだ GPU ドライバの分(約 30MB)はアプリを閉じるまで残ります。

### 画質

| 選択肢 | 中身 | 向いている所 |
|---|---|---|
| 高画質(おすすめ) | 色の少ない所(文字や UI)は劣化なし、写真のような所は JPEG 品質 95・色の間引きなし | 家庭の LAN |
| 劣化なし | すべて劣化なし(zlib) | 速い LAN で文字を正確に |
| 標準 | JPEG 品質 80・4:2:0 | Wi-Fi・遠隔地 |
| 細い回線 | JPEG 品質 40・4:2:0、圧縮を強く | 遅い回線 |

接続中でもメニューから変えられます。iivnc-server 以外のサーバーでは、そのサーバーが対応する範囲で効きます。

## 速さのための工夫

- **要求を先に出す。** 更新を受け取り始めた瞬間(復号の前)に次の要求を出します。サーバーは次の絵の
  取り込み・符号化を、こちらの受信・復号と並行して進められます。
- **JPEG は並列に復号。** Tight の JPEG の矩形を作業スレッドに配り、Windows の WIC で並列に復号して
  画面の写しへ直接書きます(256×256 の JPEG 1 枚 0.15ms。2026-10-03 実測)。
- **描画は変わった範囲だけ。** GDI でも GPU でも、変わった範囲だけを描き直します。GPU のときは
  縮めるのにミップマップを使うので、4K を縮めても文字がちらつきません。
- **メモリを抱え込まない。** GPU へは小さな受け渡し用のテクスチャ(1024×1024 を 2 枚、交互)を通して送ります
  (相手が 4K のとき、GPU 描画の専用メモリは 約 140MB。v2 までは 205〜270MB)。
- **カーソルは手元で描く。** 相手からカーソルの形をもらい、こちらの Windows のカーソルとして出すので、
  動かしても往復を待ちません。
- **キーはスキャン コードでも送る。** 相手が対応していれば(iivnc-server、TigerVNC など)、物理的なキーの位置を
  そのまま送ります。日本語配列の 半角/全角・変換・無変換・カタカナひらがな もスキャン コードのまま届きます
  (iivnc-server がそのスキャン コードで再現するところまで確認。相手の IME が実際に切り替わるかは、
  2 台の実機ではまだ確かめていません)。

通しの速さの実測は iivnc-server の README を参照(1920×1080 で全面が毎フレーム変わる絵を、高画質で 109 更新/秒)。

## 確かめた相手

- iivnc-server: すべての画質・エンコーディングで、受け取った絵を正解と画素単位で突き合わせた
- TigerVNC 1.16.2 の Xvnc(Linux 版): Raw・RRE・Hextile・ZRLE・Tight を画素単位で一致、Tight + JPEG、VNC 認証
- RealVNC・UltraVNC・TightVNC などの Windows のサーバーでは確かめていません。

## できないこと・気をつけること

- 通信は暗号化しません(VNC の決まり)。インターネット越しには VPN か SSH のトンネルを通してください。
  暗号化した認証(VeNCrypt、RealVNC の RA2)だけを受け付けるサーバーにはつながりません。
- パスワードは 8 文字まで(VNC 認証の決まり)。「覚える」で ini に置くパスワードは、ほかの VNC と同じく
  隠しているだけで、守られてはいません。
- Ctrl+Alt+Del はキーで押しても相手へは行きません(Windows が先に取る)。メニューの「Ctrl+Alt+Del を送る」を使ってください。

## ネットワークの許可と、ini のほかに PC に残るもの

iivnc-client は自分からつなぎに行くだけで待ち受けないので、ふつうは Windows の「ネットワークへのアクセスを
許可しますか」は出ません。それでも Windows ファイアウォールにこの exe の規則があれば、接続の画面の左下の
**「ネットワークの許可を消す」** で消せます(管理者の確認が出ます。この場所の exe の規則だけを消します)。
規則が無いときは「ネットワークの許可: なし」と出て、押せません。

iivnc-client 自身が書くのは ini と、`log=1` のときのログ(どちらも exe と同じ場所)だけです。
ほかには、起動したアプリすべてに Windows が付ける記録(表示名の控え、起動回数など)があるだけです
(2026-10-04、この PC のレジストリを検索して確かめた)。

## ini で選べること(画面からは選べないもの)

- `render=gdi`(既定)/ `render=gpu` … 描画の方式。上の「描画」を参照(接続の画面・メニューからも選べます)。

## コマンド ライン

```
iivnc-client.exe [サーバー] [-password <pw>] [-viewonly] [-fullscreen]
                 [-quality high|lossless|normal|low] [-ini <path>] [-log]
                 [-render gdi|gpu]
iivnc-client.exe -remove-firewall   管理者で: ファイアウォールの、この exe の規則を消す
```

## ビルド

Visual Studio 2022 Build Tools(C コンパイラ。fxc でシェーダーも作る)で `build.bat`。
`iivnc-client.exe` ができます。アイコンは `python tools/make-icon.py` で作り直せます。
